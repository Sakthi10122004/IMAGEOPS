How ImageOps Works Under the Hood

From your local drive to compressed ZIP in milliseconds—without a single byte leaving your computer.

Stage 01

Virtual File Tree Ingestion

Uses the native HTML5 FileSystem and webkitGetAsEntry APIs to recursively map entire nested folders directly into browser memory.

Stage 02

GPU-Accelerated Decode

Utilizes createImageBitmap() to decode image pixels asynchronously on background GPU threads, preventing UI lockups even with huge files.

Stage 03

OffscreenCanvas Re-sampling

Applies high-precision bicubic interpolation on OffscreenCanvas, optimizing aspect ratios and resizing dimensions without memory leaks.

Stage 04

Hardware Native Codec Encoding

Leverages native browser rasterization pipelines for WebP, AVIF, JPEG, and PNG, stripping EXIF tracking headers for total privacy.

Stage 05

In-Memory JSZip Stream

Compressed output blobs are streamed into an in-memory JSZip archive, reconstructing the exact original folder directory hierarchy.

Stage 06

Zero-Cloud Instant Delivery

Generates an instant blob: download link directly into your OS Downloads folder. No server bandwidth limits or queue waits.

Frequently Asked Questions

Can I process nested folders containing subdirectories?
Yes! When you select a folder or drag-and-drop a folder structure, ImageOps preserves every nested directory path in the generated ZIP archive.
What happens if my browser doesn't support AVIF encoding?
ImageOps detects hardware and browser codec capabilities dynamically. If your browser lacks AVIF encoding support, you can switch seamlessly to WebP with similar high-compression benefits.
Does stripping EXIF metadata affect image visual quality?
Not at all. EXIF metadata contains GPS coordinates, camera models, and timestamps. Removing it eliminates privacy liabilities and shaves extra kilobytes off every file with zero visual degradation.
Is there a file size or batch quantity limit?
ImageOps is limited only by your computer's RAM. It processes files in batches of concurrent workers to keep memory overhead lean and steady, easily handling hundreds of images in a single run.
