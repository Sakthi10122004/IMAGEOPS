Frequently Asked Questions

How does in-browser PDF to Word conversion work?
ImageOps uses Mozilla's PDF.js library to parse text runs, font sizes, line heights, and coordinates. It groups text into logical paragraphs and headings, and compiles a valid OpenXML .docx document using JSZip.
How does in-browser PDF compression reduce file size?
PDFs are typically large due to high-resolution embedded images. ImageOps renders pages at target screen DPI, compresses image streams at customized JPEG quality levels, and re-assembles the document using pdf-lib.
Can I extract tables from PDFs into Excel?
Yes! The PDF to Excel tool scans tabular text alignments and converts them into rows and columns, exported into genuine Microsoft Excel (.xlsx) or CSV files via SheetJS.
Are my documents safe when deployed on Vercel?
100% safe. Vercel acts strictly as a static file host serving the HTML, CSS, and JS files. All document parsing, conversion, and compression occur locally inside your own browser window.
